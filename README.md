# 中途任務點最佳路線規劃

本專案以台北捷運路網為基礎，研究如何在起點與終點之間安排中途任務點，並綜合考量交通時間、轉乘次數與任務需求，尋找合適的行程路線。

目前處於資料整理階段，已建立捷運路網、起訖站票價，以及臺北市、新北市、基隆市的夜市位置資料。後續將加入任務條件與路線最佳化演算法。

## 目前資料

資料存放於 [`taipei_mrt/`](taipei_mrt/)。

| 檔案 | 用途 |
| --- | --- |
| `stops.csv` | 車站名稱、座標與所屬主線。 |
| `lines.csv` | 捷運主線代碼與名稱。 |
| `route_edges.csv` | 相鄰站之間的有向連接與行駛秒數。 |
| `transfers.csv` | 同一車站不同站碼之間的轉乘關聯。 |
| `fares.csv` | 每次進站到出站的票價，僅保留起站、訖站與票價三欄。 |

詳細欄位與資料限制請參考 [台北捷運資料說明](taipei_mrt/README.md)。

夜市資料存放於 [`night_markets/`](night_markets/)，包含 64 筆夜市名稱、地址與經緯度，以及附近捷運站候選關聯。收錄範圍、座標品質與來源請參考[夜市資料說明](night_markets/README.md)。這是公開資料整理版本，並非已逐一實地查核的完整營業名冊。

票價採官方 2026-08-30 版本，包含至 **2026-09-28** 的廣慈／奉天宮站通車優惠；使用其他日期前須更新。
