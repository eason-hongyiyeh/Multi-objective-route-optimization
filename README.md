# 捷運資料地圖

將 `data/` 的車站、出入口、軌道、夜市與景點顯示在網頁地圖上，左側以勾選表控制顯示，點選地圖可查看資訊。

## 檔案用途

| 檔案 | 用途 |
| --- | --- |
| `mrt_map.py` | 啟動本機網站，讀取與檢查 GeoJSON，並將景點 JSON 轉成顯示用點位。只使用 Python 標準函式庫。 |
| `map.html` | 地圖畫面、圖層勾選表、車站與出口資訊、夜市步行路徑，以及景點開放時間和費用。 |
| `calculate_market_walks.py` | 查詢步行路網，計算夜市到 20 分鐘內最近捷運站的路徑；資料更新後需重新執行。 |
| `walking/market_stations.json` | 夜市到最近捷運站的距離、時間及路線座標，供地圖使用。 |
| `data/mrt_station.geojson` | 158 筆具站名的車站位置，以及站碼、路網等來源欄位。 |
| `data/mrt_tracks.geojson` | 256 筆捷運資料：31 筆路線、225 筆路線節點（224 筆有停靠用途、1 筆未提供用途）。 |
| `data/airportmrt.geojson` | 117 筆機捷資料：70 筆軌道、3 筆普通車方向路線、44 筆停靠點。 |
| `data/nightmarket.geojson` | 35 筆夜市位置、名稱，以及補查的營業時間、來源與待確認說明。 |
| `data/AttractionList_with_fee_and_hours.json` | 從暫存資料夾複製的 35 筆景點；包含名稱、座標、地址、開放時間、免費入場標記與費用說明。 |
| `nightmarket_hours.md` | 全部夜市的營業時間查詢表，包含來源連結與尚未確認的項目。 |
| `data/mrt_exits.geojson` | 510 筆有效出口點；已刪除汐科入口，補入 10 筆已確認出口。新莊副都心 2 號出口使用機捷原檔，避免重複。 |
| `data/airport_mrt_exits.geojson` | 36 筆機場捷運出入口，包含站名、站碼、出口代碼與設施資訊。 |
| `data/mrt_exits_clean.geojson` | 510 筆清理後出口，是 `assign_exit_station.py` 的輸入。 |
| `data/mrt_exits_with_station.geojson` | 510 筆出口的車站對照；包含 10 筆已確認歸屬與其他原有配對結果。 |
| `clean_exits.py` | 清理出口格式、無效座標與重複資料，另外輸出清理檔。 |
| `assign_exit_station.py` | 保留已確認的車站歸屬，其他出口以最近車站配對，另外輸出成果。 |
| `.gitignore` | 排除虛擬環境及 Python 快取。 |

## 開啟方式

在本資料夾執行：

```powershell
python mrt_map.py
```

瀏覽器會自動開啟。保持終端機開啟，按 `Ctrl+C` 關閉。若連接埠被占用，可用 `python mrt_map.py --port 0`；不想自動開啟瀏覽器可加 `--no-browser`。

點選夜市可看中文營業時間、來源連結與查詢日期。2026-10-19 查詢共找到 26 筆政府網站時段及 1 筆非官方報導；另外 8 筆因名稱不明、資料矛盾、未查得時段或曾公告停業而保留待確認。完整結果見 [夜市營業時間查詢表](nightmarket_hours.md)，查詢日期不代表現場營業確認日期。

地圖使用 [Leaflet](https://leafletjs.com/) 與 [OpenStreetMap](https://www.openstreetmap.org/copyright) 街道底圖，需要網路連線。

## 地圖顯示

- 拖曳列表與地圖中間的分隔線可拉寬／縮窄列表；窄螢幕改為上下拖曳調整高度。連按兩下分隔線恢復預設大小，也可聚焦分隔線後用方向鍵調整。地圖左上角「收合列表／展開列表」可切換，瀏覽器會記住大小與收合狀態，地圖自動配合剩餘空間調整。
- 白心圓點表示車站，邊框依路線配色；同筆車站有多條線時使用深色邊框。
- 左側每條路線各有「站點」與「路線」勾選框；「全部」列可一次控制所有站點或所有線段。站點包含車站與路線節點。轉乘站只要任一所屬路線仍勾選站點，就保留顯示；未能分類的資料列於「未分類」。
- 新北投、小碧潭支線獨立控制，分別包含北投、新北投與七張、小碧潭的車站標記。
- 放大至第 14 級以上自動顯示可見車站的站名及站碼，隱藏站點時也會隱藏標籤。
- 路線末端自動裁切至車站在路線上的投影位置。僅修改畫面上的幾何，不修改 GeoJSON、站名或路線資訊。
- 機捷車站加上「機場捷運」區別同名站。側欄提供圖層勾選表。
- 點選車站可看站碼、路線、營運單位、地址與原始欄位；路線直接依 GeoJSON 站碼判別，不讀取舊 CSV。
- 同名但不同位置的車站資料各自保留。
- 夜市以桃紅色實心圓顯示，預設開啟；點選可看名稱、來源 ID、經緯度及來源提供的地址、營業時間、電話等。放大後顯示名稱。
- 夜市圖層目前只有點位，「路線」欄停用。
- 景點以青綠色實心圓顯示，左側「景點」列的「站點」勾選框可獨立開關，預設開啟；「路線」欄停用。點選可看景點名稱、地址、開放時間、入場方式、費用說明、來源 ID 與座標；放大至第 14 級以上顯示名稱。內容依 JSON 原文顯示，免費入場與額外活動費用分別列出。
- 「夜市步行路徑」列的「路線」勾選框可開關全部步行線，預設顯示現有 20 條路徑，以桃紅色虛線表示。滑鼠移到線上或點選可看夜市、目的車站、距離與時間；「查看完整路徑」可縮放至該條路徑。
- 夜市資訊內仍可顯示／隱藏該夜市的個別步行路徑；僅部分路徑開啟時，側欄勾選框顯示部分勾選狀態。「全部」的路線開關也控制步行線；站點開關與步行線互相獨立。資料過期或讀取失敗時不顯示舊路徑，側欄顯示原因。
- 「捷運出入口」為藍色小實心圓、「機場捷運出入口」為紫色小實心圓，各自勾選顯示；「路線」欄停用。滑鼠移上可看名稱，點選可看出口編號、座標及原始欄位；機捷另顯示站名、站碼、位置說明及電梯等設施。
- 510 筆 OSM 出口均可顯示，其中 10 筆有已確認的車站資訊。其餘來源未提供車站對照時會保留提示；有 81 筆未提供 `ref`，原始名稱若含編號仍保留顯示。
- 機捷出口檔案更新日期為 2018-12-04，未包含 A22 老街溪站出口；座標只到小數點後三位，後續計算精確出入口步行路徑前需補齊及核對。既有夜市步行結果仍到車站座標。
- `nightmarket.geojson` 只保留 35 筆夜市資料，程式直接顯示檔案中的點位。筆數是來源紀錄數，同一夜市的分區或不同物件可能重疊；不自動合併，也不讀取舊夜市 CSV。

車站與軌道三份檔案共 531 筆，全部具有效座標：158 筆車站、269 筆路線節點、94 筆線段及 10 筆多線幾何。加上 35 筆夜市、兩份出口資料與 35 筆景點，七份檔案共 1,147 筆，全部具有效座標可顯示。其中路線節點有 268 筆具停靠用途、1 筆用途未提供。不同檔案可能有重疊資料，筆數不等於不重複的車站數。圖資可能包含施工路段或不同更新時間的資料，不代表即時營運狀態。

捷運與機捷圖層支援 `LineString`、`MultiLineString` 路線及 `@relations` 成員資訊。線段、站點、資訊視窗色標及左側色標一律使用 `map.html` 的 `routeColors`，依提供的路網圖設定近似配色，不宣稱為官方精確色碼。文湖線棕色、淡水信義線紅色、松山新店線綠色、中和新蘆線橘黃色、板南線藍色、環狀線亮黃色、三鶯線淺藍色、機場捷運淡紫色、新北投支線粉紅色、小碧潭支線黃綠色。線條不透明，避免重疊造成深淺差異；原始 `colour` 欄位保留但不控制顯示。轉乘站採深灰色，未分類採灰色。街道底圖由 OpenStreetMap 提供，底圖配色不受此設定影響。

點選可看來源物件 ID、起訖、方向與成員用途；新北投及小碧潭支線會顯示支線名稱。來源的名稱與起訖欄位若互相矛盾，保留原始內容供核對。

小實心點表示路線節點，依所屬路線配色，多線共用節點採深色。以相同 OSM 節點 ID 對照 `mrt_station.geojson`，可補上 98 筆路線節點的站名、站碼；不以距離猜測。其餘缺少站名的停靠點會明確標示，沒有成員用途的節點不會當成停靠點。

`mrt_tracks.geojson` 與 `airportmrt.geojson` 有 47 筆相同來源 ID，原始資料各自保留，畫面依所屬路線統一控制顯示。以上筆數是資料筆數，不是去重後的站數。

## 更新資料

夜市到捷運站的步行計算：

```powershell
python calculate_market_walks.py
```

- 起點使用 `data/nightmarket.geojson`，終點使用 `data/mrt_station.geojson`。按可步行路徑長度找最近車站，包含資料中的機場捷運站；每個夜市最多一條結果。
- 速度固定為每秒 1 公尺，上限 20 分鐘（含），即 1,200 公尺。超過上限不列入結果；夜市仍可點選，顯示「20 分鐘步行範圍內沒有捷運站」。
- 結果只存 `walking/market_stations.json`，不再產生 CSV。每筆保留夜市 ID、車站 ID、站名、站碼、路徑公尺數、秒數與路徑座標；若道路有時段限制會附註。檔案最外層保留資料核對碼、速度、上限及已計算夜市清單，避免誤用舊結果。
- 開啟地圖會顯示全部有效步行路徑，左側「夜市步行路徑」可統一開關；點線可看距離與時間，點選夜市也可顯示／隱藏個別路徑。目前終點是捷運站座標，尚未改算到指定出入口。
- 使用 [Valhalla](https://valhalla.github.io/valhalla/api/route/api-reference/) 的 `pedestrian`、`shortest=true` 查詢步行路網。直線距離只用來排除不可能更近的候選，不當成步行距離；不使用捷運軌道充當步行道路。
- 路由使用夜市與車站座標附近的可步行道路，未必是指定出入口；不含座標與道路的偏移、站內步行、停留或紅綠燈。超過 150 公尺的座標偏移、非步行路段或查詢失敗會中止計算。
- `walking/.cache/` 為重算用的路由回應快取，不供網站顯示；`--refresh` 可重新查詢路網。夜市或車站資料修改後，重新計算並重啟地圖；僅修改 `opening_hours` 或 `opening_hours_*` 時段欄位不影響路徑，重啟地圖即可。平常開啟地圖不會重新查詢。

端點裁切以同路線車站為候選，僅處理距端點 1 公里內、距路線 150 公尺內且沿線裁切不超過 1 公里的部分；不裁閉合線段、不刪除超過半條路線，也不延長原本未達車站中心的線。新北投與小碧潭支線分別限用其兩端車站。缺少適合車站時保留原線形，此功能為視覺整理，不代表真實軌道在車站處結束。

新增、修改、刪除或重新命名 `data/` 中的 `.geojson` 後，重新啟動程式並重新整理網頁。路線選項依實際載入的資料建立；出口檔案使用上述檔名，便可顯示在各自的勾選列。

資料需為 GeoJSON `FeatureCollection`，使用 WGS84 經緯度（經度在前、緯度在後）。支援點、線、面及其複合幾何。車站點依 `public_transport=station` 或 `railway=station` 辨識。缺少或無效座標會略過，檔案讀取失敗會顯示原因，原始檔不會被修改。

景點另外支援 `data/AttractionList_with_fee_and_hours.json`：讀取 `Attractions` 陣列，以 `AttractionID` 識別地點，將 `PositionLon`、`PositionLat` 轉成顯示用的 GeoJSON 點位，保留所有原始欄位。缺少或無效座標會略過並提示。這份檔案是獨立副本；修改暫存資料夾的來源後，需重新複製至 `data/`，再重啟程式、重新整理網頁。

`taipei_mrt/` 與 `night_markets/` 的舊資料保留，目前程式不讀取。
