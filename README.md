# 中途任務點最佳路線規劃

本專案以台北捷運路網為基礎，研究如何在起點與終點之間安排中途任務點，並綜合考量交通時間、轉乘次數與任務需求，尋找合適的行程路線。

目前處於資料整理階段，已建立捷運車站、路線、站序、站間行駛時間與轉乘關聯的 CSV 資料。後續將加入任務點資料與路線最佳化演算法。

## 目前資料

資料存放於 [`taipei_mrt/`](taipei_mrt/)。

| 檔案 | 用途 |
| --- | --- |
| `stops.csv` | 車站名稱、座標與所屬主線。 |
| `lines.csv` | 捷運主線代碼與名稱。 |
| `routes.csv` | 各營運區間的起點與終點。 |
| `route_stops.csv` | 各營運路線的往返方向與停靠站序。 |
| `route_edges.csv` | 相鄰站之間的有向連接與行駛秒數。 |
| `transfers.csv` | 同一車站不同站碼之間的轉乘關聯。 |

詳細欄位與資料限制請參考 [台北捷運資料說明](taipei_mrt/README.md)。
