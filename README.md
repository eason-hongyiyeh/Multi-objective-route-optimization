# 捷運資料地圖

將 `data/` 的車站與軌道顯示在網頁地圖上，可搜尋站名／站碼、切換圖層、定位及點選查看資訊。

## 檔案用途

| 檔案 | 用途 |
| --- | --- |
| `mrt_map.py` | 自動讀取 `data/` 與子資料夾中的 GeoJSON，檢查座標並啟動本機網站。只使用 Python 標準函式庫。 |
| `map.html` | 地圖畫面、站名標籤、路線資訊、搜尋與圖層開關。 |
| `data/mrt_station.geojson` | 159 筆車站位置，包含 158 筆有站名的資料，以及站碼、路網等來源欄位。 |
| `data/mrt_tracks.geojson` | 捷運軌道與設施範圍。 |
| `data/airportmrt.geojson` | 機場捷運軌道路徑。 |
| `.gitignore` | 排除虛擬環境及 Python 快取。 |

## 開啟方式

在本資料夾執行：

```powershell
python mrt_map.py
```

瀏覽器會自動開啟。保持終端機開啟，按 `Ctrl+C` 關閉。若連接埠被占用，可用 `python mrt_map.py --port 0`；不想自動開啟瀏覽器可加 `--no-browser`。

地圖使用 [Leaflet](https://leafletjs.com/) 與 [OpenStreetMap](https://www.openstreetmap.org/copyright) 街道底圖，需要網路連線。

## 地圖顯示

- 白心圓點表示車站，邊框依路線配色；同筆車站有多條線時使用深色邊框。
- 放大至第 14 級以上顯示站名及站碼，可用「放大地圖時顯示站名」開關控制。
- 搜尋支援中文、英文站名及站碼，例如 `西湖`、`BR16`、`R10`、`A1`、`LB10`。機捷車站加上「機場捷運」區別同名站。
- 點選車站可看站碼、路線、營運單位、地址與原始欄位；路線直接依 GeoJSON 站碼判別，不讀取舊 CSV。
- 同名但不同位置的車站資料各自保留；一筆缺少站名的資料顯示「未提供站名的捷運站」。

目前三份檔案共 1,308 筆，其中 778 筆可顯示（159 筆車站、614 筆線段、5 筆設施範圍），530 筆沒有幾何座標而略過。不同檔案可能有重疊資料，筆數不等於不重複的車站數。圖資可能包含施工路段或不同更新時間的資料，不代表即時營運狀態。

## 更新資料

新增、修改、刪除或重新命名 `data/` 中的 `.geojson` 後，重新啟動程式並重新整理網頁。圖層依實際存在的檔案建立，已移除的出入口資料不再顯示。

資料需為 GeoJSON `FeatureCollection`，使用 WGS84 經緯度（經度在前、緯度在後）。支援點、線、面及其複合幾何。車站點依 `public_transport=station` 或 `railway=station` 辨識。缺少或無效座標會略過，檔案讀取失敗會顯示原因，原始檔不會被修改。

`taipei_mrt/` 與 `night_markets/` 的舊資料保留，目前程式不讀取。
