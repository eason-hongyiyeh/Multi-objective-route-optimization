# 捷運路線規劃與演算法比較

輸入起站與終站，比較六個演算法的路線、旅程時間與票價，以暴力搜尋作為對照組。資料讀取與終端機輸入輸出統一由 `route_planner.py` 處理。

## 程式檔案

| 檔案 | 用途 |
| --- | --- |
| `route_planner.py` | 主程式：讀取捷運資料、建立路網、呼叫演算法，並顯示路線、時間、票價與比較結果。 |
| `mrt_map.py` | 讀取 `data/` 的軌道與出入口圖資，搭配車站 CSV，啟動本機地圖並開啟瀏覽器。 |
| `map.html` | 互動捷運地圖：顯示軌道、設施及出入口，支援車站搜尋、圖層切換、縮放與資訊視窗。 |
| `dijkstra.py` | 使用 Dijkstra 找最短時間路線，並提供各演算法共用的資料結構與工具。 |
| `astar.py` | 使用 A*，透過剩餘時間的下界估計引導搜尋，找最短時間路線。 |
| `bfs.py` | 使用 BFS 找最少邊數的路線；行車與轉乘各算一條邊，不保證時間最短。 |
| `floyd_warshall.py` | 使用 Floyd–Warshall 計算所有節點對的最短路徑，再取出指定起終點的結果。 |
| `k_shortest_paths.py` | 使用 Yen 演算法找出前 K 條路線，依時間等成本排序。 |
| `brute_force.py` | 使用 DFS 窮舉不重複搜尋節點的路徑，剪去不可能更好的分支，找出最短時間路線作為對照組；最壞情況可能很慢。 |

六個演算法共用主程式建立的路網，不自行讀取 CSV。比較摘要優先以暴力搜尋結果為基準；BFS 比較最少邊數，K-shortest 則以第一條路線比對最短成本。

在本資料夾執行 `python mrt_map.py` 可開啟地圖，按 Ctrl+C 關閉服務。地圖元件使用 [Leaflet](https://leafletjs.com/)，街道底圖使用 [OpenStreetMap](https://www.openstreetmap.org/copyright)，需要網路連線。修改資料後重新啟動地圖服務即可載入。

## 地圖資料（`data/`）

| 檔案 | 用途 |
| --- | --- |
| `mrt_tracks.geojson` | 依來源座標描繪軌道路徑與設施範圍，不再以相鄰站直線代替軌道。 |
| `mrt_exits.geojson` | 顯示捷運出入口位置，點選可查看名稱、出口編號及來源的無障礙通行標記。 |

兩份檔案是 OpenStreetMap／Overpass 圖資。軌道檔共 1,075 筆，可顯示 542 筆線段、5 筆設施範圍；出入口檔共 527 筆，可顯示 505 個點。其餘 550 筆沒有幾何座標，略過顯示且不修改原檔。圖資包含環狀線、機場捷運、機廠、側線與未營運路段，不代表即時營運狀態。

路線依原始 `ref` 或明確的路線名稱分類；無法辨識者歸入「其他軌道／設施」。出入口沒有可靠的路線關聯，採獨立圖層切換，不以最近車站猜測所屬路線。車站搜尋與轉乘站標記仍使用 `taipei_mrt/stops.csv`、`lines.csv`；地圖顯示不會改動路徑演算法的路網。

## 捷運資料（`taipei_mrt/`）

| 檔案 | 用途 |
| --- | --- |
| `stops.csv` | 車站代碼、站名、所屬路線與經緯度。 |
| `lines.csv` | 捷運路線代碼與名稱。 |
| `route_edges.csv` | 相鄰車站的連接關係與行駛時間。 |
| `transfer_walking.csv` | 轉乘與支線換車的連接關係及所需時間。 |
| `fares.csv` | 起站到終站的整趟票價。 |
| `station_departures.csv` | 官方各站預定發車時刻，區分平日與假日，包含新北投、小碧潭支線；文湖線沒有固定時刻表。 |
| `first_last_trains.csv` | 官方各站各方向的首末班車時間；原始資料的疑義以 `source_issue` 標記。 |
| `README.md` | 捷運資料的欄位、來源與使用說明。 |

## 夜市資料（`night_markets/`）
