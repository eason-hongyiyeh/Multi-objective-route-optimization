# 中途任務點最佳路線規劃

本專案以台北捷運路網為基礎，研究如何在起點與終點之間安排中途任務點，並綜合考量交通時間、轉乘次數與任務需求，尋找合適的行程路線。

目前已建立捷運路網、起訖站票價，以及臺北市、新北市的夜市位置資料，並提供終端機最短時間查詢。後續將加入夜市任務條件與路線最佳化演算法。

## 終端機最短時間查詢

需要 Python 3.9+，不需安裝額外套件。在本資料夾執行：

```sh
python route_planner.py
```

依提示輸入起站、終站，例如「西門」與「動物園」。支援中文站名、`臺`／`台`、站名後加「站」，以及完整站碼（如 `BL11`、`BR01`）。`list` 列出站名，`q` 離開；一次查詢後可繼續輸入下一組。也可直接執行：

```sh
python route_planner.py --start 西門 --end 動物園
python route_planner.py --start BL11 --end BR01 --transfer-minutes 0
```

程式輸出完整站序、預估最短時間、行駛／轉乘時間、換車地點及票價。採 Dijkstra 演算法，以「行駛秒數＋轉乘估算」最小為目標；時間相同時優先較少換車，再比較行駛路段數。轉乘站的多個站碼視為同一實體車站，起終點自動選擇適合的路線。



執行驗證：

```sh
python -m unittest discover -s tests -v
```

## 目前資料

資料存放於 [`taipei_mrt/`](taipei_mrt/)。

| 檔案 | 用途 |
| --- | --- |
| `stops.csv` | 車站名稱、座標與所屬主線。 |
| `lines.csv` | 捷運主線代碼與名稱。 |
| `route_edges.csv` | 相鄰站之間的有向連接與行駛秒數。 |
| `transfers.csv` | 同一車站不同站碼之間的轉乘關聯。 |
| `fares.csv` | 每次進站到出站的票價，僅保留起站、訖站與票價三欄。 |

詳細欄位與資料限制請參考 [台北捷運資料說明](taipei_mrt/README.md)。
