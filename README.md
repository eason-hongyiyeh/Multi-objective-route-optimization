# 捷運與周邊地點地圖

| 資料夾／檔案 | 用途 |
| --- | --- |
| [data/](data/README.md) | 存放捷運車站、路線、出口，以及夜市、景點、飯店和餐廳資料。 |
| [walking/](walking/README.md) | 存放夜市步行路線、距離、時間，以及景點步行篩選紀錄。 |
| [mrt_excel/](mrt_excel/README.md) | 捷運站名、路段時間、轉乘步行、票價及發車班表等 CSV，查詢時直接讀取。 |
| [imports/](imports/README.md) | 存放抓取的餐廳與景點候選、原始回應及缺漏報告；地圖顯示最新完整一批候選。 |
| [fetch_recommendation_data.py](fetch_recommendation_data.py) | 抓取並清理 OSM 餐廳與景點；`--clean-latest` 可只清理最新下載資料。 |
| [calculate_market_walks.py](calculate_market_walks.py) | 計算夜市到最近捷運站點的道路步行路徑，保留 20 分鐘（1,200 公尺）內的結果。 |
| [map.html](map.html) | 網頁地圖、遊玩行程推薦表單、圖層勾選與地點資訊。 |
| [itinerary_query.js](itinerary_query.js) | 遊玩推薦表單送出、行程卡片及道路步行路徑顯示。 |
| [itinerary_planner.py](itinerary_planner.py) | 本機條件推薦所選捷運站周邊 1 個景點＋1 間餐廳，整合捷運班表、出口配對及道路步行。 |
| [route_query.js](route_query.js) | 繪製推薦行程中的捷運路線；已移除獨立捷運查詢介面。 |
| [route_planner.py](route_planner.py) | 整合 CSV，以 Dijkstra 比較班次，計算預估最早抵達路線與票價。 |
| [fare_calculator.py](fare_calculator.py) | 全票與一般電子票證計費：北捷／環狀線依轉乘條件併計，機捷及三鶯線分段收費，符合條件的三鶯線轉乘減 8 元。 |
| [mrt_map.py](mrt_map.py) | 啟動本機網站，載入 data/、imports/ 最新候選，提供地圖資料與路線查詢 API。 |

在 `mrt-route` 資料夾執行 `python mrt_map.py`，開啟終端機顯示的網址。左側只保留遊玩行程推薦，捷運搭乘方式、時間與票價會整合在推薦結果中。同名出發站請選搭乘路線；國定假日需手動勾選。修改 CSV 後請重啟程式。

左側「遊玩行程推薦」可選出發站、目的地捷運站、時間、景點偏好、餐廳關鍵字與可用總時間。目的地可輸入站名、站碼或從建議清單選擇，預設台北車站；同站北捷轉乘路線會比較抵達時間，機捷與環狀線分開處理。欄位下方顯示當地出口、景點與餐廳候選數量，資料不足會說明缺少項目。下載資料主要涵蓋台北車站周邊，選其他目的地不會自動下載或改推其他區域。

採本機規則，尚未連接學校 LLM；餐廳關鍵字比對名稱與料理標籤。先找目的地站點 1,300 公尺內候選，再以道路路徑檢查每段步行最多 1,200 公尺、每秒 1 公尺，另外驗證所選出口到餐廳也在 1,200 公尺內。候選數量不代表已通過步行與營業時間檢查，未提供分類的既有景點僅列入「不限」。最多比對 3 組可行組合，不宣稱全區最佳解；首次查詢可能需約 40 秒，路網查詢失敗不改用直線距離。

營業時間僅判讀基本 OSM 時段，無法判讀就顯示待確認；出站、遊玩、用餐時間為表單設定的估計值。票價只包含捷運，不含門票、餐費與回程。建物外框中心、已知非地面樓層與疑似重複點不作為步行目的地。步行由 [Valhalla](https://valhalla.github.io/valhalla/) 查詢並快取於 `walking/.cache/`。

票卡選單預設「一般電子票證」，也可改選不折扣的「一般全票」。北捷與環狀線站內轉乘併計；板橋、新埔／新埔民生指定站外轉乘以 20 分鐘為界，超時分開計費。機捷、三鶯線各自分段收費；同一張悠遊卡／一卡通／icash 一般卡於 1 小時內北捷與三鶯線直接轉乘可減 8 元，例如永寧到鶯桃福德為 20＋35－8＝47 元，全票或不符合優惠條件時為 55 元。機捷不適用這筆 8 元折扣。網站以預估步行時間判斷，實際依出入閘門時間及票卡使用規定；尚未實作其他優待票或定期票。推薦結果顯示全票、折扣及合計；詳見[票價規則與案例](docs/full_fare.md)。測試：`python -B -m unittest discover -s tests -v`。

出口座標沿用原始 GeoJSON，不改寫資料、不用車站中心代替出口。優先使用來源站碼／站名；台北車站 M1～M8 保留既有[北捷官方出口表](https://web.metro.taipei/pages2026/WebStation/051/1)配對。缺所屬站的一般出口，僅在距最近車站不超過 300 公尺、與第二近車站至少相差 50 公尺時配對，結果會標明為座標推定。缺編號、地下街、緊急／禁止通行、待確認座標及歸屬不明的出口不納入；有明確歸屬但距車站超過 600 公尺也不使用。

左側「下載餐廳」「下載景點」可勾選顯示 imports/ 最新完整一批資料，按「查看下載範圍」移到該區域。空心點只在滑鼠移入時顯示名稱，點擊可看時間、來源與缺漏；尚未核對營業時間或篩選步行 1,200 公尺。相同 ID 的既有地點不重複顯示。下載新一批資料後請重啟地圖。

機捷平假日使用相同班表。文湖線使用 `BR-EST-1`、`BR-EST-2` 班距估算表：平日尖峰 3 分鐘、離峰與假日 7 分鐘、23:00 後 12 分鐘，兩端 06:00 首班、次日 00:00 末班；沿途依路段時間推算，查詢會標示「班距估算」，不是官方逐班時刻。估算不含資料未提供的途中停站或中途站始發列車；票價缺漏會標示「資料待補」。
