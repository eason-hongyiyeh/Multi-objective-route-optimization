# 台北捷運 CSV 資料說明
## 1. stops.csv：車站主檔
## 2. lines.csv：主線主檔
## 3. route_edges.csv：相鄰站路段與行駛時間
## 4. transfer_walking.csv：轉乘關聯與步行時間
## 5. fares.csv：進站到出站的票價
## 6. station_departures.csv：官方各站預定發車時刻








範圍包含文湖線、淡水信義線、松山新店線、中和新蘆線、板南線，以及新北投、小碧潭支線與區間車，並包含廣慈／奉天宮站。
目前亦包含環狀線與機場捷運；不包含淡海輕軌、安坑輕軌及貓空纜車。





## 1. stops.csv：車站主檔

每列代表一個**站碼**，唯一識別欄位是 `stop_id`。
轉乘站可能有多個站碼，例如大安站的 `BR09` 與 `R05` 分成兩列；兩個站碼之間的轉乘關聯記錄在 `transfer_walking.csv`。
本資料共有 158 個站碼，涵蓋 7 條主線。

| 欄位 | 說明 |
| --- | --- |
| `stop_id` | 捷運站碼 |
| `stop_name` | 站名 |
| `lat`、`lon` | 車站代表點緯度、經度，使用 WGS84 十進位度。 |
| `line_id` | 所屬主線代碼，關聯 `lines.csv`。 |





## 2. lines.csv：主線主檔

每列代表一條主線，唯一識別欄位是 `line_id`。

| 欄位 | 說明 |
| --- | --- |
| `line_id`、`line_name` | 主線代碼與中文名稱。 |





## 3. route_edges.csv：相鄰站路段與行駛時間

每列代表一個**有方向的相鄰站路段**，唯一識別欄位是 `edge_id`。
例如 `BR01 → BR02` 與 `BR02 → BR01` 分開記錄。目前共 303 筆，其中 `A22 → A21` 有一筆同秒數的重複紀錄；查詢程式載入時去重為 302 個方向路段，不改寫 CSV。

| 欄位 | 說明 |
| --- | --- |
| `edge_id` | 路段唯一 ID。 |
| `from_stop_id`、`to_stop_id` | 路段起點與終點，皆關聯 `stops.csv`。 |
| `travel_time_s` | 兩站間的純行駛秒數。 |





## 4. transfer_walking.csv：轉乘關聯與步行時間

<!--同一站有好幾條線交叉在一起-->
目前共 48 筆，記錄車站或轉乘通道之間的方向與預估步行秒數。
例如大安站 `BR09 → R05` 與 `R05 → BR09` 各一筆。

| 欄位 | 說明 |
| --- | --- |
| `from_stop_id`、`to_stop_id` | 轉乘起點與終點站碼。 |
| `transfer_time_s` | 官方預估轉乘步行秒數。 |
| `station_name` | 車站中文名稱。 |

`R22 ↔ R22A` 的 180 秒代表北投主線與新北投支線的轉乘步行，程式只在北投實際換車時加入；北投到新北投仍須另計候車及 157 秒行駛。七張轉小碧潭、大橋頭換往另一分支依本專案設定不加轉乘步行，仍須等待下一班車。





## 5. fares.csv：進站到出站的票價

共 15,564 筆：北捷 14,884 筆、環狀線內 196 筆、機捷內 484 筆。未收錄環狀線與北捷之間的跨線起訖票價。複合主鍵為 `from_stop_id`、`to_stop_id`，CSV 僅保留以下三欄。

| 欄位 | 說明 |
| --- | --- |
| `from_stop_id` | 進站站碼，關聯 `stops.stop_id`。 |
| `to_stop_id` | 出站站碼，關聯 `stops.stop_id`。 |
| `fare_twd` | 票價，新臺幣元；原始資料取自官方「優惠票價[金額]」欄位，同站碼起訖依本專案設定調整為 0 元。 |

查詢使用搭乘系統內的起訖票價，不逐站加總；跨機捷則將各系統搭乘段相加，尚未套用跨系統優惠。不同站卻為 0 元的 `R01 ↔ R02` 仍需核對，程式會標示票價待補，不顯示免費。





## 6. station_departures.csv：官方各站預定發車時刻

共 **101,930 筆**，涵蓋板南線、松山新店線、中和新蘆線、淡水信義線、環狀線及機捷，包含新北投及小碧潭支線；文湖線班表尚未提供。

| 欄位 | 說明 |
| --- | --- |
| `route_id` | 官方營運區間代碼，區分全程車、區間車與支線。 |
| `stop_id` | 發車站碼，關聯 `stops.csv`。 |
| `destination_stop_id` | 目的站碼，關聯 `stops.csv`。 |
| `service_type` | `weekday`：平日；`weekend_holiday`：週末及國定假日；`saturday`：週六；`sunday_holiday`：週日及國定假日。機捷的 `unspecified` 依使用者確認視為每日相同班表。 |
| `departure_time` | 預定發車時間，`HH:MM`，臺灣時間；不是實際到站紀錄。 |
| `departure_day_offset` | 0：營運當天；1：次日凌晨。例如 `00:12` 搭配 1，代表前一營運日延續至次日 00:12 的班次。 |

查詢會在上車與換車時找下一班列車；同車途中各站不重複計算候車。班表沒有逐班列車識別碼及途中停站秒數，因此抵達時間是發車時間加路段行駛時間的估算，不是完整列車到站時刻。機捷目前以逐站路段計算，尚無直達車專用時間。

日期自動區分平日、週六及週日；國定假日由網頁手動勾選，適用於所選日期的營運日。跨午夜會同時查前一營運日延續的班次，但前後日期若遇國定假日，仍需另核對班表。
