# walking：步行路線與篩選結果

這個資料夾存放路網計算結果。夜市路線與景點篩選使用的終點不同，分別說明如下。

| 檔案／資料夾 | 內容與用途 | 地圖是否使用 |
| --- | --- | --- |
| [market_stations.json](market_stations.json) | 夜市到捷運車站點位的步行路線、距離、時間與對應車站。目前有 17 筆。 | 是，用來畫「夜市步行路徑」虛線。 |
| [attraction_exit_filter.json](attraction_exit_filter.json) | 景點到捷運出口的 1,200 公尺步行篩選紀錄，記錄保留、移除、待確認原因，以及移除前的景點資料。 | 不直接顯示，是供核對的篩選報告。 |
| `.cache/` | 路網服務回應的快取。裡面以雜湊值命名的 JSON 各保存一組查詢回應，讓重複計算可使用已查過的結果。 | 不直接顯示，供計算程式使用。 |




## attraction_exit_filter.json

這是一次篩選的紀錄，不會隨景點檔自動更新：原有 52 筆景點，30 筆符合 1,200 公尺條件、21 筆移除、1 筆待確認，最後保留 31 筆。

- `results`：各景點的篩選狀態、原因、出口與距離等結果。
- `removed_records`：當時移除的 21 筆景點原始紀錄，方便日後核對；不會因此重新顯示在地圖上。
- `summary`、`notes`：統計、計算條件與限制。

此報告以景點現有座標到**捷運出口**的路網距離篩選；通過的出口是已驗證可達的終點，不代表已確認為所有出口中最近的一個。漁人碼頭因現有資料缺少淡海輕軌而保留待確認，不算已通過距離條件。
