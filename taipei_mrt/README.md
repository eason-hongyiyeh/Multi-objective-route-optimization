# 台北捷運 CSV 資料說明



範圍包含文湖線、淡水信義線、松山新店線、中和新蘆線、板南線，以及新北投、小碧潭支線與區間車，並包含廣慈／奉天宮站。
整理後的路網不包含環狀線、淡海輕軌、安坑輕軌、機場捷運及貓空纜車。



## 1. stops.csv：車站主檔

每列代表一個**站碼**，唯一識別欄位是 `stop_id`。
轉乘站可能有多個站碼，例如大安站的 `BR09` 與 `R05` 分成兩列；兩個站碼之間的轉乘關聯記錄在 `transfer_walking.csv`。
本資料共有 122 個站碼，對應 109 個不同站名。

| 欄位 | 說明 |
| --- | --- |
| `stop_id` | 捷運站碼 |
| `stop_name` | 站名 |
| `lat`、`lon` | 車站代表點緯度、經度，使用 WGS84 十進位度。 |
| `line_id` | 所屬主線代碼，關聯 `lines.csv`。 |




## 2. lines.csv：主線主檔

每列代表一條主線，唯一識別欄位是 `line_id`。

| 代碼 | 名稱 | 站數 |
| --- | --- | --- |
| `BR` | 文湖線 | 24 |
| `R` | 淡水信義線 | 29 |
| `G` | 松山新店線 | 20 |
| `O` | 中和新蘆線 | 26 |
| `BL` | 板南線 | 23 |

| 欄位 | 說明 |
| --- | --- |
| `line_id`、`line_name` | 主線代碼與中文名稱。 |




## 3. route_edges.csv：相鄰站路段與行駛時間

每列代表一個**有方向的相鄰站路段**，唯一識別欄位是 `edge_id`。
例如 `BR01 → BR02` 與 `BR02 → BR01` 分開記錄。共用路段已去重，共 234 筆，不再依營運區間重複列出。

| 欄位 | 說明 |
| --- | --- |
| `edge_id` | 路段唯一 ID。 |
| `from_stop_id`、`to_stop_id` | 路段起點與終點，皆關聯 `stops.csv`。 |
| `travel_time_s` | 兩站間的純行駛秒數。 |





## 4. transfer_walking.csv：轉乘關聯與步行時間
<!--同一站有好幾條線交叉在一起-->
每列代表同一車站內，從一個站碼連接到另一個站碼的方向與官方公佈之真實步行秒數。
例如大安站 `BR09 → R05` 與 `R05 → BR09` 各一筆。

| 欄位 | 說明 |
| --- | --- |
| `from_stop_id`、`to_stop_id` | 轉乘起點與終點站碼。 |
| `transfer_time_s` | 官方預估轉乘步行秒數。 |
| `station_name` | 車站中文名稱。 |

## 5. fares.csv：進站到出站的票價

共 14,884 筆，涵蓋現有 122 個站碼的所有起訖組合，包含同站進出。複合主鍵為 `from_stop_id`、`to_stop_id`，CSV 僅保留以下三欄。

| 欄位 | 說明 |
| --- | --- |
| `from_stop_id` | 進站站碼，關聯 `stops.stop_id`。 |
| `to_stop_id` | 出站站碼，關聯 `stops.stop_id`。 |
| `fare_twd` | 官方「優惠票價[金額]」欄位，新臺幣元；一般旅客本次乘車票價。 |
